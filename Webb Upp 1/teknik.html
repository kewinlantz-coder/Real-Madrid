TEKNIK & VERKTYG

Verktygen bakom webbsidan.

För att skapa en modern hemsida behövs flera olika tekniker och verktyg. Under kursen har jag framför allt arbetat med HTML, CSS och JavaScript.

GRUNDEN

HTML, CSS & JavaScript

De här tre teknikerna arbetar tillsammans för att skapa moderna och interaktiva webbplatser.
01 </>

STRUKTUR

HTML

HTML står för HyperText Markup Language och används för att skapa strukturen på en webbsida.

Med HTML kan jag skapa exempelvis rubriker, texter, bilder, länkar, knappar och olika sektioner.

<h1>Min hemsida</h1>
<p>Min första text.</p>
02 { }

DESIGN

CSS

CSS står för Cascading Style Sheets och används för att bestämma hur hemsidan ska se ut.

Med CSS arbetar jag med färger, storlekar, mellanrum, animationer, layout och hur sidan fungerar på olika skärmstorlekar.

h1 {
  color: white;
  font-size: 50px;
}
03 JS

FUNKTIONER

JavaScript

JavaScript används för att göra webbsidor mer interaktiva och lägga till olika funktioner.

Det kan till exempel användas för menyer, animationer, quiz, formulär och saker som händer när användaren klickar på något.

button.addEventListener("click", () => {
  console.log("Klick!");
});

SAMARBETE

Hur fungerar de tillsammans?

HTML, CSS och JavaScript har olika uppgifter, men tillsammans skapar de en komplett webbplats.

Jag brukar tänka att HTML är själva grunden, CSS bestämmer hur allt ska se ut och JavaScript bestämmer vad som ska kunna hända på sidan.
