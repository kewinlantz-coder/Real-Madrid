WEBBENS HISTORIA

Från enkla webbsidor till dagens internet.

Webben har förändrats väldigt mycket sedan den skapades. Från början bestod webbsidor mest av text och länkar, medan dagens webbplatser kan innehålla video, animationer, appar och avancerade funktioner.

VAD ÄR WEBBEN?

Internet och webben är inte samma sak

Internet är nätverket som kopplar samman datorer och andra enheter över hela världen. World Wide Web är en tjänst som använder internet för att visa webbsidor och länka ihop information.

När vi öppnar en webbläsare och går in på en hemsida använder vi alltså webben, medan själva informationen skickas genom internet.

TIDSLINJE

Webbens utveckling

Några viktiga delar av utvecklingen från början av World Wide Web till den moderna webben.
1989

BÖRJAN

Idén om World Wide Web

Tim Berners-Lee arbetade på CERN och tog fram ett förslag på ett system där information kunde kopplas samman genom länkar.

Tanken var att göra det enklare för forskare att dela och hitta information.

1990

GRUNDEN

HTML, HTTP och URL

Flera av teknikerna som fortfarande används på webben började utvecklas. HTML användes för att strukturera innehåll och HTTP gjorde det möjligt att överföra information mellan webbläsare och servrar.

1991

PUBLICERING

Den första webbplatsen

Tim Berners-Lee publicerade den första webbplatsen. Den var väldigt enkel och bestod framför allt av text och länkar.

Detta var början på World Wide Web som senare skulle bli tillgängligt för människor över hela världen.

1993

WEBBLÄSARE

Webben blir mer tillgänglig

Webbläsaren Mosaic gjorde webben enklare att använda och kunde visa både text och bilder. Det gjorde att fler började intressera sig för webben.

1995

JAVASCRIPT

Webbsidor blir interaktiva

JavaScript utvecklades under 1995. Det gjorde det möjligt att skapa webbsidor som kunde reagera på vad användaren gjorde.

I dag används JavaScript till allt från enkla knappar till avancerade webbapplikationer.

1996

DESIGN

CSS förändrar webbdesign

CSS gjorde det möjligt att skilja designen från HTML-innehållet. Utvecklare kunde styra färger, typsnitt, storlekar och layout på ett bättre sätt.

2000-talet

WEB 2.0

Sociala och interaktiva webbplatser

Under 2000-talet blev webben mycket mer interaktiv. Användare kunde själva skapa innehåll, kommentera och kommunicera med andra.

Sociala medier, videosajter, bloggar och andra webbtjänster växte snabbt.

2010-talet

MOBILEN

Responsiv webbdesign

När smartphones blev vanligare behövde hemsidor fungera på många olika skärmstorlekar. Responsiv webbdesign blev därför allt viktigare.

En modern webbplats behöver fungera bra på både mobil, surfplatta och dator.

Idag

MODERN WEBB

Webben fortsätter utvecklas

Dagens webbplatser kan fungera nästan som vanliga program. Vi använder webben för exempelvis shopping, streaming, sociala medier, spel, utbildning och arbete.

Teknikerna fortsätter utvecklas och därför behöver även webbutvecklare fortsätta lära sig nya saker.
