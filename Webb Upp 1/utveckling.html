MIN UTVECKLING

Från grunderna till egna webbprojekt.

Under kursen har mina kunskaper inom webbutveckling utvecklats steg för steg. Jag har gått från att lära mig grunderna i HTML till att kunna kombinera HTML, CSS och JavaScript i större projekt.

MIN RESA

Från början till nu

När kursen började hade jag mindre erfarenhet av webbutveckling. Under kursens gång har jag fått arbeta med fler tekniker och mer avancerade projekt.
01

I BÖRJAN

Grundläggande kunskaper

I början fokuserade jag mycket på att förstå hur en webbsida är uppbyggd och hur HTML fungerar.

  • Skapa rubriker och text
  • Lägga in bilder och länkar
  • Skapa enkla menyer
  • Förstå HTML-strukturen
  • Använda grundläggande CSS
02

NU

Större webbprojekt

Nu kan jag kombinera flera tekniker och bygga större webbplatser med bättre struktur, design och funktioner.

  • Bygga webbplatser med flera sidor
  • Skapa responsiv design
  • Använda Flexbox och CSS Grid
  • Skapa funktioner med JavaScript
  • Felsöka och förbättra min kod

STEG FÖR STEG

Så har jag utvecklats

01

HTML

Jag lärde mig grunden

Det första steget var att förstå HTML och hur man bygger strukturen på en webbsida. Jag lärde mig hur olika element används för rubriker, text, bilder, länkar och menyer.

02

CSS

Jag började arbeta med design

Efter HTML började jag arbeta mer med CSS. Jag lärde mig att ändra färger, storlekar, mellanrum och placering av olika delar på hemsidan.

Jag började också använda Flexbox och Grid för att skapa bättre layouter.

03

JAVASCRIPT

Hemsidorna blev interaktiva

När jag började använda JavaScript kunde jag skapa fler funktioner på mina hemsidor.

Jag har bland annat arbetat med menyer, knappar, quiz, sökfunktioner och animationer. Det gjorde att mina projekt blev mer interaktiva.

04

RESPONSIV DESIGN

Jag började tänka på olika skärmar

Jag lärde mig att en hemsida inte bara ska fungera på en dator. Den behöver också vara enkel att använda på mobil och surfplatta.

Därför började jag använda media queries och anpassa layouten efter olika skärmstorlekar.

05

PROBLEMLÖSNING

Jag blev bättre på att hitta fel

En stor del av webbutveckling är att lösa problem. Koden fungerar inte alltid direkt, och därför har jag blivit bättre på att testa olika lösningar och hitta fel i min kod.

Jag försöker nu lösa problemen steg för steg istället för att ändra flera saker samtidigt.

06

STÖRRE PROJEKT

Jag kan kombinera mina kunskaper

I mina senare projekt har jag kunnat använda HTML, CSS och JavaScript tillsammans.

Jag kan nu planera en webbplats, bygga strukturen, skapa designen och lägga till funktioner i samma projekt.
